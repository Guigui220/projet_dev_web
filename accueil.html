Description du projet développement WEB

Le projet consiste à créer un site web permettant de visualiser et d'analyser les données d'un réseau de bornes de recharge pour véhicules électriques (IRVE). Le site doit offrir une interface conviviale pour les utilisateurs, leur permettant de consulter les informations sur les bornes, telles que leur emplacement, leur disponibilité et leur état de fonctionnement. De plus, le site doit fournir des statistiques et des analyses sur l'utilisation des bornes, afin d'aider les gestionnaires du réseau à prendre des décisions éclairées pour améliorer le service.
